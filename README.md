# Pong Game

A simple Pong Game developed using Python. The game includes paddle controls, ball movement, collision detection, and real-time score tracking in a classic 2D style.

## Features

* Two-player gameplay
* Smooth paddle movement
* Ball collision detection
* Score tracking system
* Simple and interactive interface

## Controls

* **W** → Move Left Paddle Up
* **S** → Move Left Paddle Down
* **↑ (Up Arrow)** → Move Right Paddle Up
* **↓ (Down Arrow)** → Move Right Paddle Down

## Technologies Used

* Python
