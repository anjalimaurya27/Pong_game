# Pong Game 

A classic Pong game built using HTML, CSS, and JavaScript. This project features smooth paddle controls, realistic ball movement, collision detection, and score tracking for an interactive gaming experience.

## Features

* Two-player gameplay
* Smooth paddle movement
* Ball collision physics
* Live score tracking
* Simple and responsive design

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Controls

* Player 1: `W` / `S`
* Player 2: `↑` / `↓`

## How to Run

1. Download or clone the repository
2. Open `index.html` in your browser
3. Start playing
